\# YouRHa



For the glory of Myself



YouRHa is a personal mobile application designed to help manage daily tasks and enjoy music in a calm, Japanese-minimalist environment.



\## Planned Technology



\- React Native with Expo

\- JavaScript

\- SQLite for local data storage

\- YouTube Data API and the official embedded player

\- Katalon Studio for mobile automation testing



\## Project Goals



\- Learn mobile application development step by step.

\- Implement CRUD operations and local persistence.

\- Explore YouTube music-video search and embedded playback.

\- Practice automated testing and bug analysis.



\## Development Status



Project initialization. Application features have not been implemented yet.
